## 担当(dev-router)

- **Claude**: 計画、型とスキーマのインターフェース設計、仕様書、振り分け確認、最終レビュー。
- **Codex**: 重いタスク(判断・調査・複数ファイルにまたがるもの)、ローカルLLMが失敗したタスクの引き上げ。
- **LM Studio(LM Link)**: 定型・量産・仕様とテストが明確なタスク。
- 担当の自動判定は `dispatch.py` のスコア(unknowns / risk / size / テスト有無 / 仕様の明確さ / ファイル数)による。
