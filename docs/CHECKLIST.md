# 手動チェックリスト

各項目は「操作 → 期待する結果」です。確認できた項目だけにチェックを付けます。
未実装の項目は未チェックのまま残します。この一覧は実行済みの記録ではありません。
学習・復習・仮想日付の操作には、画面への実装後に確認する項目も含みます。
テスト用ブラウザで実施し、既存データがある場合は先に JSON を書き出します。
`fixtures/` は開発用ダミーデータで、内容の正確性は未検証です。

## 1. アンケート(`/welcome`)

- [ ] `/welcome` を開く → 言語を選ぶ初回アンケートが表示される。
- [ ] 言語・目的・期限・目標レベルを入力して進む → 回答を保ったまま次の段階へ進める。
- [ ] 期限を空にして進む → 検証エラーが表示され、完了できない。
- [ ] 有効な回答で完了する → `/data` へ移動し、回答を使ったプロンプトが表示される。

## 2. 骨組みの取り込み(`/data`)

- [ ] 骨組みプロンプトの「コピー」を押す → 貼り付け先で表示中と同じ文面を取得できる。
- [ ] 骨組みプロンプトをダウンロードする → 保存したファイルに表示中と同じ文面が入っている。
- [ ] `fixtures/dummy-skeleton.json` を貼り付けて検証する → 成功と単元数が表示される。
- [ ] 検証後に「取り込む」を押す → ホームに骨組みの単元が表示され、再読み込み後も残る。
- [ ] 骨組みの必須フィールドを削除して検証する → エラーのパスと理由が表示され、取り込めない。

## 3. 単元の取り込み

- [ ] `fixtures/dummy-unit-u01.json` を貼り付けて検証する → 件数を確認して取り込める。
- [ ] 取り込んだ単元を開く → 未検証の表示・要確認バッジが付いている。
- [ ] 内容を確認して「確認済みにする」を押す → 単元の未検証表示が消え、再読み込み後も確認済みである。
- [ ] 単元を選んで単元プロンプトをコピーする → 選んだ単元の情報が文面に含まれる。
- [ ] 履歴のある単元の JSON で一部項目を追加・削除して再検証する → 保存前に追加・削除の差分が表示される。
- [ ] 差分を確認して再取り込みする → 同じ ID の項目の FSRS 履歴が残り、教材の内容が更新される。

## 4. 学習

- [ ] ホームで学習可能な単元を選び、ステップを開始する → 対応するレッスンが開く。
- [ ] 新出のステップを進める → 単語と意味が表示され、次の項目へ進める。
- [ ] 4択で正解を選んで答え合わせする → 正解の表示が出る。
- [ ] 4択で不正解を選んで答え合わせする → 不正解と正しい答えが表示される。
- [ ] 入力問題で答えを入力して送信する → 入力内容が判定される。
- [ ] 並べ替え問題で語を並べて送信する → 並べた順序が判定される。
- [ ] 穴埋め問題に答える → 空欄への回答が判定される。
- [ ] 正解時と不正解時の表示を比べる → 色・動きが異なり、文字でも結果が分かる。
- [ ] 文法メモがある項目で答え合わせする → 関連する文法メモを読める。
- [ ] ステップの最後まで答える → 完了画面に結果が表示され、ホームに戻れる。
- [ ] 完了前後の XP を比べる → 学習結果に応じた XP が加算される。
- [ ] 同日内に再学習し、翌日にも学習する → 同日は連続日数が重複加算されず、翌日は1日増える。

## 5. 復習(`/review`)

- [ ] 期限切れと期限前の FSRS 項目がある状態で `/review` を開く → 期限切れの項目だけが出題される。
- [ ] 期限切れの項目がない状態で `/review` を開く → 復習対象がないことが分かる。
- [ ] 設定の隠しリンクから `/debug` を開き、仮想日付を次の復習期限まで進める → 対応する項目が復習対象になる。
- [ ] 仮想日付を解除する → 実際の日付に基づく復習対象に戻る。

## 6. 書き出し

- [ ] `/data` で JSON を書き出す → プロフィール・教材・学習履歴を含む JSON ファイルが保存される。
- [ ] `/data` で CSV を書き出す → 単語一覧の CSV ファイルが保存される。
- [ ] 書き出した CSV を Excel で開く → 日本語が文字化けせず、列ごとに表示される。

## 7. 読み込み

- [ ] 書き出した JSON を読み込み欄で選択して検証する → 成功と単元数が表示される。
- [ ] JSON の検証後に「置き換え」を選んで確認する → 教材と履歴が読み込んだ JSON の状態になる。
- [ ] 異なる履歴を含む JSON を「統合」で読み込む → 既存の単元を残し、同じ項目は新しい復習履歴を優先する。
- [ ] 壊れた JSON ファイルを選択して検証する → エラーが表示され、既存データは変更されない。

## 8. 設定

- [ ] UI 言語を日本語/英語に切り替える → ナビゲーションや翻訳対象のラベルが選んだ言語になる。
- [ ] 1日の目標を有効な値に変更して再読み込みする → 変更した値が保存されている。
- [ ] 学習日数/週を変更して再読み込みする → 変更した値が保存されている。
- [ ] 対応音声のある端末で読み上げをオン/オフにする → 有効時は対象語を再生でき、無効時は読み上げない。
- [ ] 対象言語の音声がない端末で設定を開く → 利用できない旨が表示され、読み上げを有効にできない。

## 9. データのリセット

- [ ] データのリセットを選ぶ → 削除前に確認ダイアログが出る。
- [ ] 確認ダイアログでキャンセルする → 教材と履歴が残る。
- [ ] 再度リセットを選んで確認する → 教材と履歴が初期化され、再読み込み後も残っていない。

## 10. 画面とキーボード

- [ ] 主要ページを Tab と Enter だけで操作する → フォーカス位置が見え、移動・実行できる。
- [ ] 4択問題で数字キー `1`〜`4` を押す → 対応する選択肢を選べる。
- [ ] OS またはブラウザで `prefers-reduced-motion` を有効にする → 学習時や画面遷移の動きが抑えられる。

## 11. スマホ

- [ ] 幅 360px・390px・430px で全ページを開く → 横にはみ出さず、必要な情報と操作を利用できる。
- [ ] 下部タブを順に押す → ホーム・復習・データ・設定へ移動でき、現在のタブが分かる。
- [ ] スマホで主要ボタンを押す → 隣のボタンを誤って押さずに操作できる大きさと間隔がある。

## 12. 公開

- [ ] `npm run build` を実行する → エラーなく終了し、`dist/` が生成される。
- [ ] `npm run preview` で表示された URL を開く → ビルドしたアプリが表示される。
- [ ] GitHub Pages の URL で各ページへ移動して再読み込みする → `#/` 形式のパスで同じ画面を開ける。
- [ ] GitHub Pages で開発者ツールの Network を確認する → リポジトリ名の配下から JS・CSS・アイコンが正常に読み込まれる。
